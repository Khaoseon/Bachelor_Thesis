# Bachelor Project: CNN Robustness and Fourier Analysis

This repository contains the code, experimental scripts, and final report for my Bachelor project on the frequency sensitivity of convolutional neural networks.

The project studies how directions from the Fourier basis can induce structured adversarial perturbations on CNNs trained on CIFAR-10 and CIFAR-100. It focuses on a targeted reproduction with convolutional models, frequency-sensitivity heatmaps, random-noise baselines, epsilon sweeps, and stability analyses.

The compiled report is available at:

```text
report/main.pdf
```

## Research Question

> How does the convolutional architecture of CNNs induce privileged vulnerability directions in the Fourier domain, and to what extent does this structural sensitivity explain the existence of universal adversarial perturbations?

## Tracked Files

- Main Python source code in `src/`.
- Experimental and figure-generation scripts in `scripts/`.
- LaTeX report sources, final figures, and compiled PDF in `report/`.
- Python environment and packaging configuration files.

## Untracked Files

The following directories are intentionally excluded from Git:

```text
data/
outputs/
docs/
```

`data/` contains locally downloaded datasets. `outputs/` contains checkpoints, logs, and heavy experimental artifacts generated by the scripts. These files can be regenerated with the commands below.

The file `report/main.synctex.gz` is also ignored: it is useful locally when editing LaTeX, but it should not be published.

## Installation

The reference environment is described in `environment.yml`.

```bash
conda env create -f environment.yml
conda activate Fourier_Adversarial_Attack
```

The project uses Python 3.12, PyTorch, torchvision, numpy, scipy, pandas, matplotlib, and scikit-learn.

## Main Commands

Show the project help:

```bash
make help
```

Train a VGGSmallBN model:

```bash
make train-vgg DATASET=cifar10
make train-vgg DATASET=cifar100
```

Generate a Fourier heatmap from a checkpoint:

```bash
make heatmap-vgg DATASET=cifar10
make heatmap-vgg DATASET=cifar100
```

Evaluate a random-noise baseline:

```bash
make random-vgg DATASET=cifar10
make random-vgg DATASET=cifar100
```

Evaluate one SFA direction across multiple epsilon values:

```bash
make sfa-eps-sweep-vgg DATASET=cifar10
make sfa-eps-sweep-vgg DATASET=cifar100
```

Check that the artifacts required for the report figures are available:

```bash
make check-figure-inputs
```

Generate the final report figures from existing experimental artifacts:

```bash
make figures
```

Compile the report:

```bash
make report
```

By default, the scripts read from and write to:

```text
data/
outputs/models/
outputs/runs/
outputs/figures/
```

These directories are ignored by Git to keep the public repository lightweight.

## Models and Datasets

Implemented models:

- `custom_cnn`: a small reference CNN.
- `vgg_small_bn`: a simplified VGG-style architecture with BatchNorm.

Datasets supported by the public code:

- `cifar10`
- `cifar100`

Datasets are loaded through `torchvision.datasets` and can be downloaded automatically by the scripts when the relevant option is enabled.

## Report

The public report is tracked with its LaTeX sources and final figures:

```text
report/main.tex
report/main.pdf
report/sections/
report/appendices/
report/figures/
```

The figures in `report/figures/` are the final figures used in the report. Intermediate artifacts used to produce them remain local in `outputs/` and are not published.

## Reproducibility Notes

The public repository allows the code to be rerun and the report to be recompiled, but it does not include trained checkpoints or heavy experimental outputs. A full regeneration of all figures from scratch therefore requires retraining the models or restoring local artifacts into `outputs/`.

The project focuses on CNNs and the CIFAR-10/CIFAR-100 datasets. Vision Transformer experiments are not included in this public repository.
